# ADR-0018: 이 서비스는 모의투자 전용이다

- 상태: 채택
- 날짜: 2026-10-06
- 관련: CLAUDE.md §0-16, §0-17, §62. 갱신: ADR-0006(인증), ADR-0012(KIS 환경)

## 결정

1. **실제 주문 · 계좌 · 자금 · 청산은 없다.** 체결은 전부 서비스 안의 체결 엔진이 시뮬레이션한다.
   실제인 것은 KIS 시세뿐이다.
2. **KIS는 시세 수신 전용이다.** 주문 · 정정 · 취소 · 잔고 · 계좌 API를 부르는 코드를 만들지 않는다.
   그래서 `KIS_ACCOUNT_NO`가 필요 없고 `.env.example`에서 뺐다.
3. **KIS 환경은 모의투자(vts)만 둔다.** `KisProperties.Environment`에서 `REAL`을 지웠다.
   `KIS_ENVIRONMENT=real`이면 설정 바인딩이 실패해 기동이 멈춘다(확인함). 별도 검사 코드는 두지 않았다.
   실전 앱키가 코드 경로에 들어올 일 자체를 없앤다.
4. **Cognito는 공개 배포 직전(Phase 11)에 붙인다.** 그 전에는 배포하지 않는다.
   지금 Mock Login은 이메일만 알면 그 사용자로 들어갈 수 있기 때문이다 (ADR-0006).
   > **예외 (ADR-0020):** 검증 배포는 Cognito 없이 한다. 인터넷 진입점이 있지만 시험 계정만 쓰고 실사용자 · 실제 개인정보는 받지 않는다.

## 대가

모의투자 앱키도 실제 시장 시세를 준다. 다만 REST 초당 한도가 실전과 다를 수 있다.
Phase 8-2의 폴링 계층 처리량이 이 한도에 묶인다. 한도는 KIS 공지로 확인해 설정에 둔다.
