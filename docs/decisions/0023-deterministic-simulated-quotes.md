# ADR-0023: 실제 시세를 받지 않는 종목에는 결정형 모의 시세를 준다

- 상태: 제안됨. 로컬 mock 모드와 EKS kis 모드에서 고정 5종목 밖의 종목을 열어 시세가 뜨고, 새로고침 · market-ingest 재시작 뒤에도 같은 시각의 값이 같으면 채택으로 바꾼다
- 날짜: 2026-10-19
- 관련: CLAUDE.md §67, §57.2, §66.2, §31, §62.2. 갱신: ADR-0022(쓰는 쪽은 ingest만 → 수요 키는 api가 쓴다)

## 배경

- 종목 마스터에는 2,719종목이 있다(Phase 8-1). 그런데 시세는 `market.pinned-symbols`에 적힌 5종목만 받는다.
- 나머지 종목은 검색과 상세 화면까지만 되고 시세가 없다. 조회는 503이고, 주문은 `MARKET_PRICE_UNAVAILABLE`로 거절된다.
- 수요 기반 KIS 구독(Phase 8-2)은 아직 없다.
- 기존 Mock 모드의 random walk에는 상태가 있었다. seed를 주지 않으면 재시작할 때마다 가격 흐름이 달라졌다. seed를 줘도 재시작하면 기준가부터 다시 시작했다.
- 요구 사항: 새로고침이나 재시작으로 시세가 바뀌면 안 된다. 해시처럼 입력이 같으면 결과가 언제나 같아야 한다.

## 결정

### 1. 시세는 `(종목코드, 기준가, 슬롯, seed)`의 순수 함수다

구현은 `SyntheticPriceModel`이다.

- **슬롯:** `floor(epochMillis / slot)`. 기본은 1초다.
- **시세 시각:** 지금 시각이 아니라 슬롯의 시작 시각이다. 그래서 timestamp까지 같은 값이 된다.
- **등락:** 정수로만 계산하는 value noise 4옥타브를 더한다.
  - 1시간 ±600bp, 10분 ±200bp, 1분 ±60bp, 5초 ±15bp. 합쳐 최대 ±8.75%다.
- **가격:** 기준가에 등락을 곱하고, 상 · 하한가(±30%) 안에 넣은 뒤 KRX 호가단위에 맞춘다.
- **거래량:** KST 자정부터 센 누적값이다. 하루 안에서는 줄지 않는다.
- **해시:** `StableHash`. FNV-1a 64와 SplitMix64를 쓴다.
  - `Random`, `String.hashCode`, `Math.sin`, 부동소수점은 쓰지 않는다. JVM · OS가 달라도 비트 단위로 같아야 하기 때문이다.
- **골든 값 테스트:** 알고리즘이나 상수가 바뀌면 깨진다. 값을 바꾸는 것은 모든 종목의 시세 경로를 바꾸는 일이므로, 이 ADR에 적고 바꾼다.

### 2. 값을 계산하는 곳은 market-ingest 하나다

구현은 `SyntheticQuoteFeed`다.

- **대상:** `(고정 종목 ∪ 시청 수요) − MarketDataProvider.realtimeSymbols()`.
- **이후 경로:** 실제 시세와 같다. `QuoteIngestService`를 거쳐 Valkey · Kafka · pub/sub로 나가고, 1분봉 · corebank 중계 · 체결까지 그대로 이어진다.
- **같은 슬롯을 두 번 내보내도 해가 없다.** 값이 바이트 단위로 같다.
  - Valkey는 같은 값으로 덮어써진다.
  - trading의 `saveIfNewer`는 같은 timestamp를 버린다.
  - 체결 중복은 상태 머신이 막는다(ADR-0011).
- **중복 억제:** 종목별 마지막 슬롯을 기억해 Kafka 중복을 줄인다. 정합성 장치는 아니다.

### 3. 실제와 모의를 한 종목에 섞지 않는다

- `MarketDataProvider.realtimeSymbols()`가 경계다.
  - kis 모드에서는 KIS가 등록한 종목(지금은 고정 종목)을 돌려준다. 이 종목은 모의 대상에서 빠진다.
  - Mock 모드에는 실제 공급자가 없다. `MockMarketDataAdapter`는 지웠고, 고정 종목도 같은 모델로 만든다.
- Phase 8-2에서 KIS가 수요에 따라 종목을 등록하면 `realtimeSymbols()`가 늘어난다. 그러면 그 종목은 자동으로 모의 대상에서 빠진다.

### 4. 시청 수요는 Valkey 정렬 집합 하나에 둔다

- 키는 `market:demand:viewers`다. member는 종목코드, score는 만료 시각(epoch ms)이다.
  - §60.2는 종목마다 키를 두는 그림이었다. 하지만 그러면 수요가 있는 종목을 나열할 때 SCAN이 필요하다. 정렬 집합이면 범위 조회 한 번이다.
- **쓰는 쪽은 market-service(api)다.** ADR-0022의 "쓰는 쪽은 ingest만"에 생기는 유일한 예외다. §57.2가 원래 계획한 구조다.
  - WebSocket SUBSCRIBE와 현재가 · 호가 REST 조회가 즉시 기록한다.
  - 10초마다 이 인스턴스의 구독 종목 전체를 다시 기록한다.
  - 기록 하나의 수명은 30초다.
  - 구독을 풀어도 지우지 않는다. 다른 세션 · 인스턴스가 보고 있을 수 있으므로 만료되게 둔다.
- 종목코드 형식(`StockSymbol`)이 아닌 값은 버린다. 형식은 맞지만 마스터에 없는 종목은 ingest가 건너뛴다.
- ingest는 틱마다 만료분을 지우고, 최근에 기록된 것부터 `max-symbols`(기본 100)개를 읽는다.

### 5. 출처를 숨기지 않는다 (§62.2)

- `MarketPrice.source`(REALTIME | SIMULATED)를 추가했다. 현재가 REST와 WebSocket PRICE에 실린다.
- 화면은 SIMULATED면 "모의 시세"를 표시한다.
- Kafka `market.price.updated` 계약은 그대로 둔다. trading은 출처가 필요 없다.
- 이 필드가 없던 때 Valkey에 쓴 값은 REALTIME으로 읽는다.

## 검토한 대안

- **상태가 있는 random walk에 seed만 고정하기:** 기각했다.
  - 재시작하면 기준가부터 다시 시작한다. 시각이 아니라 호출 횟수에 따라 값이 정해지므로 "같은 순간 같은 값"이 아니다.
- **완전 고정 가격(종목, 기준가만으로 정함):** 기각했다(사용자 결정).
  - 차트가 평평하고, 가격 조건이 맞지 않는 지정가는 영원히 체결되지 않는다.
- **api가 조회할 때마다 직접 계산하기:** 기각했다.
  - 값이 같다는 점은 매력적이다. 하지만 trading이 읽는 Valkey 값과 Kafka 이벤트는 여전히 누군가 써야 하므로, 계산하는 곳이 둘이 된다.
  - 수요 기록만 하면 쓰는 쪽이 하나로 남는다.
- **전 종목을 매 슬롯 생성하기:** 기각했다.
  - 2,700건/초가 Kafka · trading 소비자(종목마다 미체결 주문 조회) · corebank 중계로 흘러간다. 아무도 보지 않는 종목에 쓰는 비용이다.

## 결과와 제한

- 고정 종목 밖의 종목도 열면 1초 안에 시세가 생긴다. 그 종목으로 시장가 주문도 할 수 있다(슬롯 1초 < `market.price.max-age` 5초).
- 같은 시각의 시세는 새로고침 · 재시작 · 파드 수와 상관없이 같다. 같은 날 같은 시각을 다시 계산해도 같다.
- **제한: 아무도 보지 않는 종목의 미체결 지정가는 체결되지 않는다.**
  - 수요가 없으면 시세를 만들지 않기 때문이다.
  - 다시 열면 그 순간의 슬롯 값으로 이어진다. 그 사이의 경로는 판정하지 않는다.
  - 주문 수요(§57.2)는 Phase 8-2에서 넣는다. 다만 EKS에서는 corebank → channel 방향이 막혀 있어 §65.6의 방향 규칙을 따라야 한다.
- 모의 시세는 KST 정규장과 무관하게 24시간 움직인다(§59.3 Mock은 아무 때나 연습).
- 기준가는 종목 마스터를 따른다. 동기화로 기준가가 바뀌면(매 영업일 08:00) 그날의 경로가 새 기준가에서 다시 정해진다.
- `market.synthetic.seed`를 바꾸면 모든 종목의 경로가 바뀐다. 운영 중에는 바꾸지 않는다.
- 설정 키가 바뀌었다. `market.mock.*`(`MARKET_MOCK_TICK_INTERVAL`, `MARKET_MOCK_SEED`)는 없어지고 `market.synthetic.*`(`MARKET_SYNTHETIC_*`)가 생겼다. 다른 저장소(trader-gitops)에 옛 키가 있으면 지운다.
